Multiple Choice Questions

1. For a problem we face in real-world situations, what steps do we follow in what sequence?
  • a) I, II, III
  • b) II, III, I
  • c) III, II, I
  • d) II, I, III
Correct Answer: d) II, I, III
Explanation: In problem-solving, the correct order is first to understand the real-world problem (II), then make some solution (I), and finally instruct the computer to behave accordingly (III). This sequence is essential to ensure the solution meets the problem's requirements.
2. The following are types of computing problems:
I. Counting Problems
II. Search Problems
III. Decision Problem
  • a) I and II
  • b) I and III
  • c) II and III
  • d) I, II and III
Correct Answer: d) I and II and III
Explanation: The book categorizes computing problems into counting, search, and decision problems. Counting problems deal with calculations, search problems focus on finding specific items, and decision problems involve making choices.
3. Computational thinking is:
  • a) Programming
  • b) Thinking like a computer
  • c) Coding
  • d) Logically solving problems
Correct Answer: d) Logically solving problems
Explanation: Computational thinking involves approaching problems systematically and logically, which includes breaking down complex issues into manageable parts, identifying patterns, and creating step-by-step solutions, rather than merely programming or coding.
4. To solve Search problems, we need to:
  • a) Provide the moves.
  • b) Provide start state.
  • c) Provide the end state.
  • d) a, b and c
Correct Answer: d) a, b and c
Explanation: Solving search problems involves defining the moves (rules for navigating through states), a start state (where to begin), and an end state (goal to achieve). This approach ensures a clear pathway from start to goal.
5. The eight queens puzzle is the problem of:
  • a) Sorting
  • b) Searching
  • c) Counting
  • d) Both a and b
Correct Answer: b) Searching
Explanation: The eight-queens puzzle is a classic example of a search problem. The objective is to find a way to place eight queens on a chessboard so that no two queens threaten each other. This involves searching for all possible solutions.
6. Finding the location of the element with a given value is a:
  • a) Search
  • b) Traversal
  • c) Sorting
  • d) None of the above
Correct Answer: a) Search
Explanation: Searching is locating a specific element with a given value within a data structure. Traversal and sorting are related but differ in focus—traversal examines each element while sorting arranges elements in order.
7. In IPO charts, we have:
  • a) Input, Plan, Output
  • b) Input, Program, Output
  • c) Input, Process, Output
  • d) Input, Produce, Output
Correct Answer: c) Input, Process, Output
Explanation: IPO (Input, Process, Output) is a model for problem-solving that highlights how input data is processed to produce an output. This model is widely used in computational thinking and systems design.

Short Questions

Question # 1: What is the major difference between solving simple and complex problems?
Simple problems are straightforward and don’t take much time to solve. They usually need just a few clear steps. For example, adding two numbers is a simple problem. Complex problems are much harder and often must be broken down into smaller, manageable parts. Imagine trying to design a website; it has many pieces, like the layout, colors, and links, which require planning and organizing.
Question # 2: Why do software designers prefer to use IPO charts?
IPO charts (Input, Process, Output) help software designers see the entire process. They show what data (input) is needed, how the data is handled (process), and what the outcome should be (output). By organizing ideas this way, designers can plan their work more effectively, making sure each part of the program does what it’s supposed to.
Question # 3: Differentiate between Computational thinking and Logical thinking.
Computational thinking is like thinking in steps to solve a problem, as a computer would do. It involves breaking a problem into parts, finding patterns, and creating clear steps to get a solution. Logical thinking is broader—it’s about using reasoning to solve problems but doesn't necessarily involve breaking it into steps. For instance, logically thinking through a puzzle is different from creating a step-by-step process to program a game.
Question # 4: Write four properties of Computational thinking.
The four main properties of computational thinking are:
  • Decomposition - Breaking down a complex problem into smaller pieces.
  • Pattern Recognition - Finding similarities within problems, which can make it easier to solve them.
  • Abstraction - Focusing on the important details and ignoring the unimportant ones.
  • Algorithm Design - Creating a set of rules or steps to solve the problem.
Question # 5: What are the methods used to design a solution?
To design a solution, you start by understanding the problem deeply. Next, you make a plan, which may involve breaking down the problem or drawing a flowchart. Finally, after creating the solution, you test it to make sure it works well and make improvements if needed.
Question # 6: Which Computational thinking technique breaks down the problem into smaller parts?
Decomposition is the technique that helps break down a large or complex problem into smaller, more manageable parts. By tackling each smaller part individually, it becomes easier to understand and solve the whole problem.
Question # 7: Identify 3 computing problems from other subjects that you are studying in your class.
Here are examples of computing problems in other subjects:
  • Math - Solving long equations by breaking them down into simpler steps.
  • Science - Running experiments that need clear instructions and observations.
  • Geography - Analyzing data, like population statistics, which can involve calculations and data interpretation.
Question # 8: Why do we need to think computationally?
Computational thinking helps us solve problems in an organized way. It makes it easier to tackle big challenges by following logical steps, which is useful not only in computer science but also in everyday problem-solving. For example, planning a project or solving a math problem can be done more easily with computational thinking.
Question # 9: The telephone numbers usually have 9 digits. Out of these 9, the first two digits represent the area code and are constant within a given area. The last 7 digits represent the number, and it cannot begin with 0. How many different telephone numbers are possible with a given area code?
With the first two digits fixed as the area code, we only need to find the number of possible combinations for the last 7 digits. Since the first digit of these 7 can be any number from 1 to 9 (9 choices) and each of the remaining 6 digits can be from 0 to 9 (10 choices each), there are 9 million different possible numbers: 9 × 106 = 9,000,000.
Question # 10: From city A to city B, there are 4 different roads, and from city B to city C, there are 2 different roads. Identify how many possible routes are there that someone can follow to reach from city A to city C passing by city B.
Since there are 4 possible roads to travel from city A to city B, and for each of those roads, there are 2 possible roads from city B to city C, we multiply the number of choices: 4 × 2 = 8. This means there are 8 different ways to travel from city A to city C through city B.

Long Questions

Q1. Identify whether the given problems are Decision Problems, Counting Problems, or Search Problems. Write your answer in front of each problem given below:
  • Does a given binary string have an even number of zeros?
    Answer: This is a Decision Problem. A decision problem is one where we simply need a yes or no answer. In this case, we’re only interested in knowing if the binary string has an even number of zeros, without counting each zero or finding all possible counts. It’s a straightforward "yes" or "no" response.
  • Flipping a coin results in Heads or tails. I flip a coin 20 times, how many different sequences of heads and tails are possible?
    Answer: This is a Counting Problem. A counting problem is focused on finding the total number of possibilities. Here, since each flip has two outcomes (heads or tails), and we are flipping the coin 20 times, we calculate the total sequences by raising 2 to the power of 20 (since there are 2 options per flip, repeated 20 times). This shows how many unique sequences of heads and tails can be generated in 20 flips.
  • Does a certain Java program say “yes” to an empty input?
    Answer: This is a Decision Problem. Similar to the binary string question, we are just looking for a "yes" or "no" response from the Java program regarding its behavior with an empty input. Decision problems don’t require detailed steps; they only need an answer that confirms or denies a condition.
  • How many ways can the letters of the word TRIANGLE be arranged?
    Answer: This is a Counting Problem. To solve this, we count all possible arrangements of the letters in "TRIANGLE." Counting problems like this one involve calculating permutations, as each arrangement of the letters represents a unique possibility. We would consider the number of letters and calculate all possible ways to order them.
  • N-queens problem: where the goal is to place eight queens on a chessboard such that no queen attacks any other.
    Answer: This is a Search Problem. In a search problem, we’re looking for a specific arrangement or solution that meets certain criteria. Here, we need to place eight queens on a chessboard so that no two queens threaten each other, meaning no two queens can share the same row, column, or diagonal. The solution involves testing different configurations until we find a safe arrangement, which makes it a search problem.
Q2. A student has to take one course in physics, one in science, and one in mathematics. He may choose one of 3 physics courses (P1, P2, P3), one of 2 science courses (S1, S2), and one of 2 mathematics courses (M1, M2). In how many ways can this student select the 3 courses he has to take?
To find out how many ways the student can select one course from each subject, we use the rule of multiplication for counting options across categories.
  • For physics, there are 3 options: P1, P2, and P3.
  • For science, there are 2 options: S1 and S2.
  • For mathematics, there are also 2 options: M1 and M2.
By multiplying the number of choices for each subject, we get:
3 × 2 × 2 = 12

This means there are 12 possible combinations of courses the student can select. Each combination is unique, as it involves one course from each subject area. This approach highlights the concept of calculating combinations by multiplying the options available in each category.
