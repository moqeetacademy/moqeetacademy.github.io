Class 9 Computer Science Chapter 3 Notes — Programming Fundamentals NBF Syllabus

Unit Overview: This chapter covers structural web engineering, frontend styling rules, and basic scripting routines. Students learn to use HTML5 semantic tags, create design systems with Cascading Style Sheets (CSS), write functional event-driven JavaScript code, and manipulate page elements using the Document Object Model (DOM).

Key Topics Covered

  • Web Framework Architecture: Websites vs. Interactive Web Applications
  • HTML Document Flow: Structural tags, Text processing elements, Elements nesting
  • CSS Cascading Architecture: Inline rules, Local styles, and External stylesheets
  • JavaScript Execution Lifecycles: Variables initialization, Event registers, Data typing
  • Document Object Model (DOM): Node lookup patterns, Dynamic mutation, Event handlers
  • Table Compilation Frameworks, Multimedia pipelines, Scrolling text tracks

Multiple Choice Questions

1. Everything in HTML is identified based on:
  • a) Brackets
  • b) Title
  • c) Tags
  • d) Image
Correct Answer: c) Tags
Explanation: In HTML, everything is identified using "tags." Tags help define elements like headings, paragraphs, images, and links, allowing the browser to interpret and display the content correctly.
2. The output of HTML code is visible in:
  • a) Notepad
  • b) File
  • c) Browser
  • d) Spreadsheet
Correct Answer: c) Browser
Explanation: HTML code is rendered in a web browser. The browser interprets the HTML code to display the webpage as it is intended to look and function for users.
3. The name of a web page can be given using _____ tag:
  • a) Body
  • b) Title
  • c) Head
  • d) Footer
Correct Answer: b) Title
Explanation: The <title> tag is used to define the title of the webpage, which is displayed on the browser tab. It also helps in SEO (Search Engine Optimization) by providing a title for the page in search engine results.
4. The main parts of a document are arranged in _____ tag:
  • a) Head
  • b) Title
  • c) Body
  • d) Line Break
Correct Answer: c) Body
Explanation: The <body> tag contains the main content of an HTML document, including text, images, links, tables, and other elements that are displayed on the webpage.
5. The heading tag-pair for the 5th level heading is:
  • a) <h5 .. h5>
  • b) <h5 .. /h5>
  • c) <h5> .. </h5>
  • d) <h5> .. <h/5>
Correct Answer: c) <h5> .. </h5>
Explanation: The <h5> and </h5> tags are used for the 5th level of heading in HTML. HTML headings range from <h1> (largest) to <h6> (smallest).
6. Span is used to provide _____ to a line:
  • a) Font
  • b) Border
  • c) Style
  • d) Color1
Correct Answer: c) Style
Explanation: The <span> tag is commonly used to apply styles to a specific section of text without affecting other content.
7. The first row of the table in HTML is called:
  • a) Title row
  • b) Header Row
  • c) Upper Row
  • d) Top Row
Correct Answer: b) Header Row
Explanation: The first row in an HTML table is typically defined as the header row using the <th> tag, which stands for "table header." It usually contains labels or headings for each column.
8. 'p' tag-pair is used for:
  • a) Print
  • b) Page align
  • c) Page break
  • d) Paragraph
Correct Answer: d) Paragraph
Explanation: The <p> tag in HTML defines paragraphs. Text within <p> tags is displayed as a separate paragraph on the webpage, with spaces above and below it.
9. A variable cannot start with a:
  • a) Alphabet
  • b) Number
  • c) Character
  • d) String
Correct Answer: b) Number
Explanation: In programming, variables must start with a letter or an underscore; they cannot begin with a number. This rule helps avoid confusion with numeric literals.
10. The first value assigned to a variable after declaration is called:
  • a) Beginning value
  • b) Starting value
  • c) Initialization
  • d) Substitution
Correct Answer: c) Initialization
Explanation: Initialization is assigning a starting value to a variable when it is declared, allowing the variable to hold this value for use in the program.

Question # 2: What does 'href' refer to, and how is it used?

The href attribute in HTML stands for "Hypertext Reference" and is used to specify the destination URL of a hyperlink.

How to Use It:

<a href="https://www.example.com">Click Here</a>

Explanation:

  • <a> is the anchor tag that creates the link.
  • href="https://www.example.com" points to the destination address.
  • "Click Here" is the text visible to the user. Clicking it opens the referenced URL.
Question # 3: Enlist the optional parameters to open a webpage.

When using the target attribute in an HTML hyperlink, it specifies how the linked document should open. The common optional parameters are:

  • _self: Opens the linked document in the same window/tab (default behavior).
  • _blank: Opens the linked document in a new window or tab.
  • _parent: Opens the linked document in the parent frame.
  • _top: Opens the linked document in the full body of the window.
  • Custom Frame Name: Opens the linked document in a specific named frame.

Example Usage:

<a href="https://www.example.com" target="_blank">Click Here</a>

Question # 5: Explain the role of the <body> tag-pair in a document.
The <body> tag contains the main structural content of the HTML document, including text, images, links, tables, and scripts visible to the user. All content meant to be displayed on the viewport page must be enclosed within <body></body>. It follows immediately after the closure of the <head> tag-pair.
Question # 6: How is event-based code used in JavaScript?

Event-based code in JavaScript creates interactive web pages by executing scripts in response to user actions or system states.

  • Event Listener Registration: Uses addEventListener() or inline attributes to attach function calls to elements.
  • Event Handling Function: Contains logic executed when the target event runs.
  • Common Event Types: Triggers on user interactions (e.g., click, keypress, mousemove) or lifecycle hooks (e.g., load, submit).

Example:

button.onclick = function() {
    alert('Clicked!');
};
Question # 7: Infer about External CSS. Where is External CSS generally used?

External CSS: A styling architecture where design rules are written in a separate standalone document with a .css extension and linked to HTML pages using the <link> tag inside the head section.

Primary Use Cases:

  • Multi-page Management: Centralizes design tokens for large platforms, ensuring global consistency across pages.
  • Maintainability: Simplifies changes, since a single update in the external sheet updates all linked documents.
  • Performance Optimization: Enhances load times because browsers cache the external asset on the first request.

Long Questions

Q1: What is a Document Object Model (DOM)? Explain with an example.

The Document Object Model (DOM) is a cross-platform programming interface for web documents. It models an HTML or XML document as a tree structure where each element, attribute, and text snippet represents a unique object or node. This allows languages like JavaScript to modify the page structure, styles, and content dynamically.

Example Document Implementation:

<!DOCTYPE html>
<html>
<head>
  <title>DOM Example</title>
</head>
<body>
  <h1>Welcome to DOM Example</h1>
  <p id="demo">This is a paragraph.</p>
  <button onclick="changeText()">Click me</button>

  <script>
    function changeText() {
      document.getElementById("demo").innerHTML = "Paragraph changed!";
    }
  </script>
</body>
</html>

Explanation:

  • HTML Structure: Contains standard nodes: a heading, a target text node with id="demo", and an interface action element.
  • DOM Interaction API: When the user hits the button, JavaScript invokes the changeText() routine. The API method document.getElementById("demo") targets that node and changes its innerHTML value.
Q2: Write code to differentiate between different types of headings in HTML.

HTML offers six structured levels of page headings via the <h1> to <h6> tag-pairs, arranged by order of importance. Below is the implementation example:

<!DOCTYPE html>
<html lang="en>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Heading Example</title>
</head>
<body>
  <h1>This is a level 1 heading</h1>
  <h2>This is a level 2 heading</h2>
  <h3>This is a level 3 heading</h3>
  <h4>This is a level 4 heading</h4>
  <h5>This is a level 5 heading</h5>
  <h6>This is a level 6 heading</h6>
</body>
</html>

Structural Breakdown:

  • <h1> marks primary titles and page themes. Only one h1 is recommended per document for semantic clarity.
  • <h2> outlines secondary topics, and <h3> through <h6> organize nested sub-sections.
  • SEO and Accessibility impact: Screen readers and search engine indexers rely on this hierarchical heading structure to parse page content correctly.
Q3: Elaborate on Steps and Provide Code to Load a Background Image in a web page?

Loading an optimized background asset requires structured steps spanning image preparation, HTML markup definitions, and standard CSS style constraints.

Implementation Strategy Steps:

  1. Image Selection & Processing: Select an optimal layout asset (JPEG/PNG format) compressed for production web delivery.
  2. Path Management: Save the asset file to your working project directory (e.g., images/bg.jpg).
  3. HTML Markup Skeleton: Construct the base document with standard document structure tags.
  4. CSS Binding Layer: Declare the background attributes on the page body rule block.

Code Solution:

<!-- HTML file configuration -->
<!DOCTYPE html>
<html lang="en">
&head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Background Image Example</title>
  <link rel="stylesheet" href="style.css">

<body>
</body>

Q4: With the help of sample code, highlight different methods to Incorporate CSS and HTML code into a web page

There are three standard methods to introduce Cascading Style Sheets into web pages, along with modular CSS framework integrations:

1. Inline CSS Method
Styles are added directly inside the individual element tag using the style attribute. Useful for localized overrides.

<h1 style="color: red; font-size: 24px;">Inline CSS Heading</h1>

2. Internal CSS Method
Declared inside a centralized <style> block located in the document's <head> region. Best suited for single-page applications.

<head>
  <style>
    h1 { color: blue; }
    p { font-size: 18px; }
  </style>
</head>

3. External CSS Method (Production Standard)
Keeps markup and design cleanly separated by linking a dedicated .css file to the HTML page.

<head>
  <link rel="stylesheet" href="styles.css">
</head>

4. CSS Frameworks Integration Method
Imports pre-built component sheets (like Bootstrap) via a Content Delivery Network (CDN) to accelerate UI construction.

<head>
  <link rel="stylesheet" href="https://stackpath.bootstrapcdn.com/bootstrap/4.5.2/css/bootstrap.min.css">
</head>
<body>
  <h1 class="text-danger font-italic">Bootstrap Framed Heading</h1>
</body>

Q6: Discuss the functionality JavaScripts can provide in a webpage with the help of a suitable example.

JavaScript provides key frontend capabilities across three major areas:

1. Interactive Event Handling
Allows the webpage to react directly to user inputs and interactions.

<button id="btn">Click Me</button>
<script>
  document.getElementById("btn").addEventListener("click", function() {
    alert("Button execution complete.");
  });
</script>

2. Dynamic DOM Manipulation
Modifies page structures, content, or element properties on the fly without requiring a full page refresh.

<p id="text">Original Text String</p>
<button onclick="mutate()">Update</button>
<script>
  function mutate() {
    document.getElementById("text").innerHTML = "DOM node mutates successfully!";
  }
</script>

3. Client-Side Input Validation
Checks user input inside form fields before sending it to the server, reducing unnecessary processing load.

<form name="valForm" onsubmit="return validate()">
  <input type="text" name="user">
  <input type="submit">
</form>
<script>
  function validate() {
    if (document.forms["valForm"]["user"].value == "") {
      alert("Field cannot be left blank.");
      return false;
    }
  }
</script>
Q7: Articulate steps and write code to create scrolling text on a webpage.

Horizontal scrolling items can be built using native CSS keyframe pipelines or fine-tuned JavaScript timers.

Method 1: CSS @keyframes Pipeline Solution

<!DOCTYPE html>
<html>
<head>
  <style>
    .marquee-box {
      width: 100%;
      overflow: hidden;
      background: #f4f4f4;
    }
    .marquee-text {
      white-space: nowrap;
      animation: scrollTrack 12s linear infinite;
    }
    @keyframes scrollTrack {
      0% { transform: translateX(100%); }
      100% { transform: translateX(-100%); }
    }
  </style>
</head>
<body>
  <div class="marquee-box">
    <div class="marquee-text">This text continuously scrolls using pure CSS keyframes.</div>
  </div>
</body>
</html>

Method 2: JavaScript Routine Calculation Solution

<!DOCTYPE html>
<html>
<body>
  <div style="width:100%; overflow:hidden;">
    <div id="jsMarquee">Scrolling text managed by JavaScript setTimeout routines.</div>
  </div>
  <script>
    var track = document.getElementById("jsMarquee");
    function runScroll() {
      track.style.transform = "translateX(" + window.innerWidth + "px)";
      track.style.transition = "transform 10s linear";
      setTimeout(function() {
        track.style.transform = "translateX(-100%)";
      }, 100);
    }
    runScroll();
    setInterval(runScroll, 10100);
  </script>
</body>
</html>
Q8: Enlist steps to add a video clip in a website which starts playing as the web page loads.

To implement an optimized video asset configured for immediate autoplay delivery, execute the following systematic checklist:

  1. Source Encoding Optimization: Encode video targets into widely compliant formats (such as H.264 MP4 or WebM containers).
  2. Bitrate Compression: Compress media files through utility platforms (e.g., HandBrake) to optimize loading speeds.
  3. Server Allocation: Host file bundles on server pipelines or reliable object stores.
  4. HTML Markup Injection: Embed the <video> element using standard attribute tokens:
<video autoplay muted loop playsinline width="100%" height="auto">
  <source src="assets/video/clip.mp4" type="video/mp4">
  Your browser does not support the video playback elements.
</video>

Important Usability Rule: The muted attribute is required. Modern web browsers block auto-playing videos that have active audio tracks to protect the user experience.

Q10: In the context of fig 40 (d) add another button namely ‘Revert’ which when is pressed, it will reverse both the color and index value.

To extend the base code with a 'Revert' feature, we declare a dedicated revertOrder() function. This function resets the page background color and switches the numeric sequence output back to ascending order.

Complete Code Solution:

<!DOCTYPE html>
<html>
<head>
  <title>Interactive Loop Controller</title>
</head>
<body>
  <div id="outputContainer"></div>

  <script type="text/javascript">
    var index;
    var targetDiv = document.getElementById("outputContainer");

    // Initial ascending initialization output block 
    renderAscending("Initial For-Loop Stream Output Execution:");

    function renderAscending(headline) {
      var contentStr = "<strong>" + headline + "</strong><br/>";
      for (index = 0; index < 10; index++) {
        contentStr += "Index Sequence No. : " + index + "<br />";
      }
      targetDiv.innerHTML = contentStr;
    }

    // Interactive button routing operations functions
    function descOrder() {
      document.body.style.backgroundColor = "peachpuff";
      var contentStr = "<strong>Altered Descending Execution Track Array:</strong><br/>";
      for (index = 10; index > 0; index--) {
        contentStr += "Index Sequence No. : " + index + "<br />";
      }
      targetDiv.innerHTML = contentStr;
    }

    function revertOrder() {
      document.body.style.backgroundColor = "white";
      renderAscending("System State Reverted Symmetrically (Ascending Track):");
    }
  </script>

  <p style="margin-top: 20px;">Control Framework Triggers:</p>
  <button onclick="descOrder()">Descending Order</button>
  <button onclick="revertOrder()">Revert</button>
</body>
</html>
